# Hospital Patient Data Management System

A simple C++ console application for inputting, displaying, and calculating the total cost of patient data. This project was created as a basic exercise in C++ fundamentals, focusing on structs, arrays, and user input.

---

## Features

* **Dynamic Data Entry:** Register any number of patients.
* **Structured Data:** Uses C++ `struct` to store patient information (Name, Illness, Address, Cost).
* **Batch Input:** Loop through and input data for each patient one by one.
* **Data Display:** Prints a formatted summary of all registered patients.
* **Cost Calculation:** Automatically calculates and displays the total treatment cost for all patients.
